# Cuestionario final: Fundamentos de Java

Diez preguntas para repasar el curso, una por lección. Intenta responder cada una antes de mirar la respuesta correcta (✅) y la explicación corta que aparece debajo.

1. **¿Desde qué método empieza a ejecutarse un programa en Java?**
   - `start` · `run` · `main` ✅ · `print`
   - *Java siempre empieza en `public static void main(String[] args)`.*
2. **¿Qué tipo de dato usarías para guardar `75.5`?**
   - `int` · `double` ✅ · `boolean` · `String`
   - *`double` guarda números con decimales.*
3. **¿Cuánto vale `25 % 7`?**
   - 3 · 3.57 · 4 ✅ · 18
   - *`%` da el resto: 7 cabe 3 veces en 25 y sobran 4.*
4. **¿Qué operador significa «y» en una condición?**
   - `||` · `&&` ✅ · `!` · `==`
   - *Con `&&` las dos condiciones deben ser verdaderas.*
5. **¿Cuántas veces se repite `for (int i = 0; i < 5; i++)`?**
   - 4 · 5 ✅ · 6 · Infinitas
   - *i toma los valores 0, 1, 2, 3 y 4.*
6. **¿Qué palabra indica que un método no devuelve ningún valor?**
   - `return` · `static` · `void` ✅ · `null`
   - *`void` significa vacío: el método no devuelve resultado.*
7. **¿Qué palabra se usa para crear un objeto a partir de una clase?**
   - `class` · `new` ✅ · `this` · `create`
   - *`new Mascota("Toby", "perro")` crea un objeto nuevo.*
8. **¿Para qué sirve un setter con validación?**
   - Para borrar un objeto · Para cambiar un atributo privado solo si el valor es válido ✅ · Para imprimir un texto · Para crear una clase
   - *La clase protege sus datos y rechaza valores sin sentido.*
9. **En un arreglo de 3 elementos, ¿qué índices son válidos?**
   - 1, 2, 3 · 0, 1, 2 ✅ · 0, 1, 2, 3 · Solo 0
   - *Los índices empiezan en 0 y terminan en length − 1.*
10. **¿Cómo se comparan correctamente dos textos en Java?**
    - `texto1 == texto2` · `texto1 = texto2` · `texto1.equals(texto2)` ✅ · `texto1 + texto2`
    - *`equals` compara las letras; `==` compara si son el mismo objeto.*
