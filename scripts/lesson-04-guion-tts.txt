Cuando terminas una partida, el juego decide si ganaste una medalla de oro, de plata, o si debes intentarlo otra vez. Los programas toman decisiones todo el tiempo. Hoy aprenderás a hacerlo con if y else.

Abre la práctica cuatro. If significa si. Else significa si no. La estructura se lee casi como una frase: si los puntos son mayores o iguales a cien, muestra medalla de oro. Si no, muestra sigue practicando.

[00:45]
Entre los paréntesis del if va una condición, una pregunta que solo puede responderse con verdadero o falso. Si es verdadera, se ejecuta el bloque entre las primeras llaves. Si es falsa, se ejecuta el bloque del else.

[01:05]
Para escribir condiciones usamos operadores de comparación. Mayor que, menor que, mayor o igual, menor o igual. Para preguntar si dos valores son iguales usamos dos signos igual seguidos. Y para distinto, un signo de exclamación y un igual.

[01:30]
Cuidado aquí, porque es un error muy común: un solo igual guarda un valor, dos iguales comparan. En el if casi siempre necesitas dos.

[02:10]
Entre el if y el else agregamos un else if, que significa si no, si. Escribimos else if, y entre paréntesis, puntos mayor o igual a cincuenta. Dentro mostramos medalla de plata.

[02:30]
Las condiciones se revisan de arriba hacia abajo, y solo se ejecuta la primera que sea verdadera. Si escribes ciento veinte, la primera ya se cumple, así que Java no revisa las demás. Por eso el orden importa: siempre de la condición más exigente a la menos exigente.

[02:55]

[03:20]
Primero preguntamos cuántas vidas quedan y las leemos con nextInt. Luego escribimos: if, abre paréntesis, vidas mayor que cero, et et, puntos mayor que cien. Si ambas son verdaderas, mostramos desbloqueaste el nivel secreto.

[03:45]
También existe el operador o, que se escribe con dos barras verticales. Con o basta con que una de las condiciones sea verdadera. Y el signo de exclamación invierte una condición: convierte verdadero en falso.
